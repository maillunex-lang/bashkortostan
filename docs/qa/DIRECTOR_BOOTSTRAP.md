## Ограничения проверки
Точный JSON из ветки GitHub **не был передан в локальный Python runtime**, поэтому указанные локальные `check/render` не подтверждают побайтово точный файл ветки. `docs/WORK_PLAN.md` сформирован из фактического GitHub JSON совместимой логикой, но **не утверждается как результат штатного Python render**. Перед слиянием необходимо прогнать обе команды в CI или локальном клоне именно этой ветки и убедиться, что render не меняет файл. Пробное git-слияние и Godot/серверные тесты ещё не проводились.
