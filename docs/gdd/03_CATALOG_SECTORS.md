# GDD-03. Подробная структура каталога отраслей

Статус: проектное наполнение v0, не финальные SKU. Решения D-017–D-020 обязательны. **Все коэффициенты и цены: черновик**.

## 1. Охват первого релиза
Минимум **250 товаров**, **400 рецептов**, **60 типов предприятий**. Эти числа утверждены владельцем. Каждый товар имеет стабильный идентификатор и производственный/добывающий источник; каждый рецепт валидируется на доступность входов. Для сложных цепочек 3–7 стадий. Упаковка и альтернативные рецепты обязательны; сроки годности, побочные продукты и переработка отходов отложены.

## 3. Типы предприятий (проектный реестр)
**Добыча и сельское хозяйство:** зерновое поле, овощная ферма, сад, ягодная ферма, коровник, свиноферма, птицеферма, лесозаготовка, песчаный карьер, кварцевый карьер, известняковый карьер, глиняный карьер, железорудная шахта, медный рудник, угольная шахта, нефтяная скважина, газовая скважина.

**Промышленность:** элеватор, мельница, хлебозавод, макаронная фабрика, сахарный завод, маслозавод, молокозавод, сыроварня, мясокомбинат, колбасный цех, кондитерская фабрика, соковый завод, консервный завод, лесопилка, целлюлозный комбинат, бумажная фабрика, мебельная фабрика, цементный завод, бетонный завод, кирпичный завод, стекольный завод, завод стеклотары, нефтеперерабатывающий завод, химзавод, завод полимеров, завод пластиковой тары, металлургический завод, прокатный завод, машиностроительный завод, текстильная фабрика, швейная фабрика, обувная фабрика, электронный завод, завод бытовой техники.

**Торговля и услуги:** продуктовый магазин, супермаркет, гипермаркет, мясной магазин, молочный магазин, пекарня-магазин, магазин одежды, обувной магазин, мебельный магазин, строительный магазин, магазин электроники, магазин бытовой техники, аптека, автосалон, оптовый склад, логистический терминал, торговый центр, коммерческое помещение в МКД.

Реестр содержит более 60 **предлагаемых** типов; их окончательные функции, площади, мощности и экономический баланс ещё проектируются.

## 4. Примеры цепочек (рецептуры условные)
- Кварцевый карьер → стекольный завод → завод стеклотары → молокозавод → магазин.
- Коровник → молокозавод; ягодная ферма → молокозавод; химзавод → завод пластиковой тары → молокозавод (йогурт).
- Зерновое поле → элеватор → мельница → хлебозавод → магазин.
- Нефтяная скважина → НПЗ → завод полимеров → завод пластиковой тары → пищевое производство.
- Железорудная шахта → металлургический завод → прокатный завод → машиностроительный завод → магазин.

## 5. Качество и бренды
Каждая производственная партия получает целочисленный уровень качества. Варианты рецептов, оборудование и качество сырья могут изменять качество выхода; затем качество участвует в формуле привлекательности магазина и накоплении репутации бренда. **Шкала, веса и формулы не утверждены.** Товары одного SKU и разного качества нельзя молча смешивать без согласованного правила.

## 6. Формат каталогов
Предлагаемые каталоги: `data/catalog/items.json`, `recipes.json`, `enterprises.json`, `units.json`; структура описывается JSON Schema. У товара `id,name_ru,category,unit,raw,tradeable`; у рецепта `id,enterprise_type,inputs[{item,quantity}],outputs[{item,quantity}],duration_ticks`. Числа — целые положительные. У каждого SKU есть хотя бы один источник, достижимый от первичных ресурсов. Сложные цепочки тестируются автоматически.

## 7. Критерии приёмки
1. В готовых каталогах не менее 250 уникальных товаров, 400 корректных рецептов и 60 предприятий; без фиктивных дублей ради счётчика.
2. Все ID уникальны, ссылки валидны, единицы совместимы, производственные графы достижимы.
3. Есть несколько альтернативных рецептов, упаковка участвует как реальный вход, а не декоративный тег.
4. Для молочной, хлебной, стекольной, строительной и нефтехимической цепочек есть воспроизводимые тесты 3–7 стадий.
5. Не реализовывать сроки годности, отходы и побочные продукты в первом релизе.
6. Результаты симуляций совпадают с эталонами, все величины целочисленные, `ECON_CATALOG_V1` выключен по умолчанию.
