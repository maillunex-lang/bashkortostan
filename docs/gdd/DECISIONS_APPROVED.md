# Утверждённые решения владельца

## Зафиксировано из прямых сообщений владельца
- D-001: Проект отдельный, репозиторий `maillunex-lang/bashkortostan`; жанр: онлайн-экономическая стратегия в духе Capitalism Lab с реальными игроками.
- D-002: Android, горизонтальная ориентация, движок Godot.
- D-003: Мир Республики Башкортостан, старт с пяти городов; города процедурно застраиваются от центра с дорогами.
- D-004: Один игровой месяц = 24 реальных часа; серверный экономический тик каждый реальный час.
- D-005: При строительстве игроком здания дорога прокладывается автоматически за счёт собственника.
- D-006: Коммерческие помещения в МКД и ТЦ доступны для аренды с ограничением по площади.
- D-007: Разветвлённые производственные цепочки и альтернативные товары; большой ассортимент должен присутствовать уже при запуске, а не откладываться на поздние обновления.
- D-008: Две независимые линии исполнителей; исполнитель не сливает в main, приёмку и слияние делает директор.

## Не утверждено
Конкретные пять городов, количественные размеры каталога, рецепты и их пропорции, баланс, аудитория, сроки, бюджет, монетизация, правовая модель, критерии успеха, точная графика, серверная инфраструктура, запреты по механикам. Рекомендации в иных документах не равны решениям владельца.
